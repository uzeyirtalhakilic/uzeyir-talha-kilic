# Üzeyir Talha Kılıç - Windows XP Themed Personal Website

Bu proje, Windows XP işletim sisteminin klasik arayüzünü taklit eden kişisel bir web sitesidir. Next.js, TypeScript ve Tailwind CSS kullanılarak geliştirilmiştir.

This is a personal website that mimics the classic Windows XP operating system interface, built with Next.js, TypeScript, and Tailwind CSS.

## 🖥️ Features / Özellikler

- **Windows XP Desktop Experience** - Classic desktop with icons and taskbar
- **Multiple Applications** - My Computer, Control Panel, My Projects, Recycle Bin, and more
- **Winamp Player** - Functional music player with classic Winamp interface
- **Paint Application** - Simple drawing application
- **Multilingual Support** - Turkish and English language support
- **Responsive Design** - Works on both desktop and mobile devices
- **Classic Windows XP Styling** - Authentic visual design with classic icons and sounds


## 🎨 Technologies Used / Kullanılan Teknolojiler

- **Next.js 14** - React framework with App Router
- **TypeScript** - Type-safe JavaScript
- **Tailwind CSS** - Utility-first CSS framework
- **React** - UI library
- **Internationalization** - Multi-language support

## 📱 Applications / Uygulamalar

- **My Computer** - File system explorer
- **Control Panel** - System settings and configurations
- **My Projects** - Portfolio showcase
- **Recycle Bin** - Deleted items and cheats
- **Winamp** - Music player with classic interface
- **Paint** - Drawing application
- **Who Am I** - Personal information

## 🌐 Internationalization / Uluslararasılaştırma

The website supports multiple languages:

- Turkish (tr)
- English (en)

Language switching is available through the footer menu.

## 🎵 Audio Features / Ses Özellikleri

- Classic Windows XP system sounds
- Winamp music player with MP3 support
- Authentic audio experience
